## Enumération Web

nous avons déjà identifier le fichier `robots.txt` dans le scan nmap

accédons au site web et après vérifions le contenue du fichier `robots.txt`

![](/assets/img/echo-web.png)

nous avons un portais de télémétrie réseau, un champ `IP Adresse`  et conteur de paquet qui est règle sur `2 packets` il s'agit un outil de diagnostique réseau qui nous perme de vérifier la connectivite d'une adresse IP.

**Remarque:** si le champ n'est pas bien assainir nous allons faire passe a une vulnérabilité d'injection de commande dans le champs `target`

![](/assets/img/echo-ping.png)

comportement normal et donne attendu, essayons d'injecter une commande

![](/assets/img/echo-id.png)

comportement inattendu par le développeur, la commande a été bien exécuter et la sortie est retourne dans la réponse

lisons le fichier `index.php` pour apprendre davantage sur le comportement du programme de maintenance réseau

![](/assets/img/echo-cs.png)


```
<?php
$output = "";
$searched_target = "";

if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_POST['target'])) {
    $searched_target = $_POST['target'];
    $target = trim($searched_target);
    $count = isset($_POST['count']) ? intval($_POST['count']) : 2;
    if ($count < 1 || $count > 4) $count = 2;

    if (empty($target)) {
        $output = "[-] Error: Target host or IP address is required.";
    } elseif (preg_match('/[;`]/', $target)) {
        $output = "[-] Security Warning: Semicolons and backticks are strictly filtered by the Echo Network Appliance.";
    } else {
        $cmd = "ping -c " . $count . " " . $target . " 2>&1";
        $output = shell_exec($cmd);
    }
}
?>
```


le `;` est blacklisté 

**code vulnérable:**

```
$cmd = "ping -c " . $count . " " . $target . " 2>&1";
        $output = shell_exec($cmd);
```

l'entre utilisateur n'est assaini, elle est aussi directement passer dans la fonction `shell_exec` qui exécute des commandes système

```bash
clara@echo:~$ cat /usr/local/bin/echo-report
#!/usr/bin/env python3
import os
import sys

# Load internal reporting module
sys.path.insert(0, "/opt/echo")

try:
    import reporter
except ImportError as err:
    print(f"[-] Critical Error: Failed to import reporter module: {err}")
    sys.exit(1)

def main():
    print("==================================================")
    print("     Echo Appliance - System Diagnostics Summary  ")
    print("==================================================")
    reporter.run_report()

if __name__ == "__main__":
    main()

import os
import subprocess

def run_report():
    print("[*] Running network diagnostic checks...")
    subprocess.run(["ip", "-brief", "address"])
    print("\n[*] System memory utilization:")
    subprocess.run(["free", "-h"])
    print("\n[*] System uptime:")
    subprocess.run(["uptime"])
    print("\n[+] Diagnostic report completed successfully.")
```

c'est programme sert a un diagnostique réseau en utilisant la librairie `subprocess` pour exécuter des commande
