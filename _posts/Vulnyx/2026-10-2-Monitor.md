nous avons de utilisateur pour l'escalade nous allons passer de www-data --> kevin --> root

comme nous avons un fichier  `htpasswd` qui bloque notre accès au moment de l'énumération web nous allons lire la configuration apache pour trouver l'emplacement de ce fichier et de le lire

```bash

<Directory />
	Options FollowSymLinks
	AllowOverride None
	Require all denied
</Directory>

<Directory /usr/share>
	AllowOverride None
	Require all granted
</Directory>

<Directory /var/www/>
	Options Indexes FollowSymLinks
	AllowOverride None
	Require all granted
</Directory>

<Directory /var/www/site>
	Options Indexes FollowSymLinks
	AllowOverride None
	Require all granted
	Options -Indexes
</Directory>

<Directory /var/www/site/.admin/>
	AuthType basic 
	AuthName "Admin Login"
	AuthUserFile /etc/apache2/.htpasswd
```
